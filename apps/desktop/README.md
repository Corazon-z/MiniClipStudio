# 桌面应用入口

路径：`apps/desktop/`。整个仓库是产品，本目录是一个职责模块。

## 职责

组装Win32窗口与应用控制，不执行长时间媒体处理。

## 状态与实施规则

2026-11-11建立目录。说明文件用于保留目录和解释边界，不代表功能完成。实际代码与迁移状态以docs/MODULES.md和工作记录为准。

先完成正确、可验证功能，再根据测量优化；每个新函数解释输入/输出、错误、所有权和线程。不得把占位类当成实现；不为每个目录机械增加DLL或线程。

- `main.cpp`：Win32窗口创建/按钮/定时器/关闭请求；媒体和线程交src处理。

这里只实现列出的基础能力；其余功能继续按阶段验收，不宣称完整商业质量。

## 控制台退出信号

ConsoleStopSignal.h为窗口入口登记C/Break处理器，只跨线程传atomic请求；main和独立CameraWindow/VideoPreviewWindow定时器消费后走WM_CLOSE。GUI不在控制台回调中释放编码器或等待线程；CLI处理器保持独立。
