# S02实施与教学记录

用户最初要求S03；核对源码仅有S01，询问后用户明确选择“按顺序先实现S02”。本轮只实现S02，不把S03标完成。

1. 阅读当前任务控制器、CLI、媒体资源与工程配置，检查本地SDK的swscale/PNG API；沿用SDK和现有项目。
2. 最小新增视频模块：普通自有结果、同步函数、取消异常；逐包解码第一条非封面视频，首帧按行跨度转RGB24并PNG编码，继续解码并排空统计，临时输出成功后才发布。
3. 取消/资源/错误和输出所有权显式表达，限制支持格式，说明旋转、SAR、HDR及损坏检查边界；不做性能优化或大型结构迁移。
4. 增加独立C API延迟视频样本、Python真实像素/行方向/帧数与失败验证；两个配置编译和视频/旧音频/探测回归均通过。
5. 更新公共使用/路线/进度和本地两份笔记、逐文件详解、运行过程、VS入门、源码快照。新增50组历史问答及来源索引、面试回答/简历模板和代码题，随后追加S02题目与成果。
