# ADR 0001：产品模块化与功能优先

2026-11-11，用户确认。背景：录音功能集中在旧AudioCapture文件，后续摄像头、编辑与AI容易混入窗口过程。

选择：整个仓库作为产品；apps管理入口，application管理用例/线程，capture管理会话，media管理FFmpeg链路；项目/渲染/编辑/AI按明确边界预留。沿用VS/Win32，不在迁移同时换Qt/CMake。目录用README保留，不生成空壳类；先功能正确再测量优化。

代价：暂时仍只有一个产品EXE；CLI与桌面共同构建，但源文件分离。WavWriter暂合并转换、PCM编码与WAV封装，等真实第二个消费者出现后再细分，避免为架构机械增加抽象。FFmpeg内部头较重和Windows路径适配后续可以继续隔离，本次不假装完全跨平台。

基础提取已完成并构建验证；发布质量、复杂状态/错误模型、设备故障/恢复仍需后续工作。结果见worklogs与MODULES。
