## 每轮学习闭环

先解释本次概念 → 画最小数据流 → 计划最小改动 → 实现并注释输入/输出/资源/线程 → 实际生成和运行 → 记录问题与测试 → 用户复述/小练习。重大GUI/构建/后端调整仍按AGENTS确认，不因有路线图就自动安装依赖或搬工程。

功能正确先行，性能后做。有限缓冲、正确格式/时间、同步、清理和取消是功能正确性的必要条件，不延后。依赖选型时记录发布条件，发行前再完整复核。
