# 播放与同步

路径：`src/playback/`。整个仓库是产品，本目录是一个职责模块。

## 职责

缓冲、时钟、seek、暂停与实时输出。

## 状态与实施规则

2026-11-11建立目录。说明文件用于保留目录和解释边界，不代表功能完成。实际代码与迁移状态以docs/MODULES.md和工作记录为准。

先完成正确、可验证功能，再根据测量优化；每个新函数解释输入/输出、错误、所有权和线程。不得把占位类当成实现；不为每个目录机械增加DLL或线程。

## S04已实现

AudioPlayer.h/.cpp管理本地音频播放：消费线程拥有WASAPI、生产线程拥有解码器，中间队列最多8个1024帧PCM块。暂停/继续、停止、音量、自然结束与失败收尾；窗口和CLI复用。音画同步/seek/视频调度属于S05，尚未实现。详见docs/AUDIO_PLAYBACK.md。
